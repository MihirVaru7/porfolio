# Shubham Bhushan Kumkar Portfolio

A modern, animated portfolio website for a video editor, VFX artist, and 3D designer.

## Features

- Modern dark theme with cyberpunk aesthetics
- Smooth animations with Framer Motion
- 3D elements with React Three Fiber
- Fully responsive design
- Multiple pages (Home, About, Projects, Services, Blog, Contact)
- Optimized performance

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber
- Three.js

## Getting Started

1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`

2. Run the development server:
   \`\`\`bash
   npm run dev
   \`\`\`

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

\`\`\`bash
npm run build
npm start
\`\`\`
